## Ответы на вопросы
1. В чём разница между полем класса и обычной переменной в функции?
*Ответ:* поле принадлежит экземпляру класса и существует пока существует экземпляр класса. переменная существует только во время выполнения функции
2. Что такое конструктор и зачем он нужен?
*Ответ:* это специальный метод, который вызывается при создании объекта, он заполняет поля объекта начальными значениями
3. Зачем нужен @override перед toString()? Что будет если его убрать?
*Ответ:* для toString — это переопределение метода класса Object, от которого в Dart неявно наследуются все классы. если не будет, то не будет защиты от опечаток
4. Чем статическое поле static int _counter отличается от обычного поля?
Сколько копий этого поля существует в программе?
*Ответ:* статическое поле принадлежит всему классу, а не определённому объекту. существует в программе только один раз
5. Что означает нижнее подчёркивание в _counter?
*Ответ:* делает переменную приватной для файла
